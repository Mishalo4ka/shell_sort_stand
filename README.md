# Сортировка Шелла на Python и C++

Из корня проекта запустите стенд через [uv](https://docs.astral.sh/uv/getting-started/installation/). uv подготовит Python 3.13. Для C++ нужен GCC или Clang с поддержкой C++17. Стенд ищет `c++` или `g++` в `PATH`. Другой путь к компилятору можно указать в `CXX`.

```sh
uv run shell-sort-stand
```

По умолчанию стенд сравнивает оба языка, семь последовательностей шагов и пять видов данных на массивах из 1 000 и 10 000 элементов. Для запуска только на Python добавьте `--languages python`. Все параметры доступны через `uv run shell-sort-stand --help`.

## Одинаковый опыт на двух устройствах

Выполните команду на каждом устройстве, меняя только `--device` (например, `laptop` или `desktop`). Для своего массива используйте `--input numbers.txt` вместо `--sizes` и `--data`. Файл принимает числа int32 через пробелы или переносы строк.

```sh
uv run shell-sort-stand --sizes 100000 --data random --gaps ciura ciura_extended --seed 911 --repeats 6 --device laptop
```

`ciura` использует фиксированные шаги до 1750. Вариант `ciura_extended` продолжает их по эмпирическому правилу `⌊2,25 × шаг⌋` и выбирается явно. [Наблюдение Циуры](https://deltami.edu.pl/media/articles/2008/11/delta-2008-11-o-sortowaniu-shella.pdf) · [Формула продолжения](https://www.scielo.br/j/tema/a/G7Ybrdy6w4K6gFYRvSj4tft/?lang=pt)

## Что измеряется

- Оба языка получают один массив и одинаковые шаги. Каждый повтор сортирует свежую копию. Таймер охватывает вызов сортировки. После него результат сверяется с эталоном. C++ собирается с `-O2`.
- При сравнении нескольких вариантов с двумя и более повторами стенд проходит пары «последовательность, язык» сначала в прямом, затем в обратном порядке. Каждая серия начинается с одного прогрева. Чётное число повторов делится между проходами поровну. При нечётном первый проход получает один дополнительный замер.
- В терминале выводится медиана в миллисекундах. В `results/*.csv` сохраняется каждый измеренный повтор в наносекундах (`time_ns`). Завершённые серии записываются сразу. При прерывании CSV может содержать часть прогона.
- Для сравнения сверяйте `sha256` входного массива, фактические шаги `gaps` и версии Python или компилятора. Короткие массивы чувствительны к разрешению таймера. Для оценки влияния данных повторяйте опыт с разными `--seed`.

Тесты, включая сборку C++ и проверку CSV: `uv run python -m unittest discover -s tests -v`.
