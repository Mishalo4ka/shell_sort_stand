Сортировка Шелла (англ. Shell sort) — вариант сортировки вставками, в котором сначала упорядочивают элементы, стоящие далеко друг от друга. Расстояние между ними называют шагом. Дональд Шелл предложил этот метод в 1959 году. [1]

Идея метода

При обычной сортировке вставками маленькому числу в конце массива приходится двигаться к началу через все бо́льшие числа перед ним. Метод Шелла позволяет за одно перемещение преодолеть сразу несколько позиций.

Выберем шаг h = 4. В одну группу попадут элементы на позициях 1, 5, 9 и далее, в другую — на позициях 2, 6, 10. Каждую такую группу сортируем вставками. Затем уменьшаем шаг и повторяем проход. При h = 1 весь массив образует одну группу, и последний проход завершает сортировку.

Пошаговый пример

Возьмём восемь чисел и исходную последовательность Шелла. Начнём с половины длины массива и будем делить шаг пополам. Получатся три прохода с шагами 4, 2 и 1. Каждое нажатие «Далее» показывает следующее сравнение в реализации на Python. В обеих строках выделена одна и та же пара позиций.

После прохода с шагом 2 на нечётных позициях стоят 2, 4, 6, 8, на чётных — 1, 3, 5, 7. Обе группы уже упорядочены. Теперь каждому из чисел 1, 3, 5 и 7 достаточно сдвинуться влево на одну позицию.

Реализация

C++ 
void shell_sort(int *arr, const int size) {
    int step = size / 2;
    while (step > 0) {
        for (int i = step; i < size; i++) {
            int j = i;
            int x = arr[j];
            while (j >= step && x < arr[j - step]) {
                arr[j] = arr[j - step];
                j -= step;
            }
            arr[j] = x;
        }
        step /= 2;
    }
}
Python 
def shell_sort(data: list[int]) -> list[int]:
    step = len(data) // 2
    while step > 0:
        for i in range(step, len(data)):
            j = i
            while j >= step and data[j - step] > data[j]:
                data[j - step], data[j] = data[j], data[j - step]
                j -= step
        step //= 2
    return data

Последовательности шагов

Среднее время работы алгоритма зависит от длин промежутков — d, на которых будут находиться сортируемые элементы исходного массива ёмкостью N на каждом шаге алгоритма. Существует несколько подходов к выбору этих значений:

АвторКак выбираются шагиФормулаПри N = 16Время в худшем случае [5]
Дональд Шелл Делим длину массива пополам, затем так же уменьшаем каждый шаг с округлением вниз. ⌊N/2k⌋, k ≥ 1 8, 4, 2, 1Θ(N²)
Томас Хиббард Из каждой степени двойки вычитаем единицу. 2k − 1, k ≥ 1 15, 7, 3, 1Θ(N3/2)
Воган Пратт Берём все произведения степеней двойки и тройки. 2p · 3q, p, q ≥ 0 12, 9, 8, 6, 4, 3, 2, 1Θ(N log² N)
Дональд Кнут Начинаем с единицы. Чтобы получить следующий член ряда, утраиваем предыдущий и прибавляем единицу. [2] (3k − 1)/2, k ≥ 1 13, 4, 1Θ(N3/2)
Марчин Циура В справочнике OEIS приведены девять экспериментально подобранных шагов: 1, 4, 10, 23, 57, 132, 301, 701, 1750. [3] [OEIS] Задано списком 10, 4, 1Θ(N²) для этих девяти шагов
